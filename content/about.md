# 이 위키에 대하여
<!-- source: wiki/README.md -->

근거 기준에 맞춰 쓰인 게임 메커니즘 위키(Animal Crossing: Wild World, 한국 발매판 "ADMK"):
모든 주장은 등급과 출처를 달고 있으며, 독자는 이를 심볼 테이블, 매칭된 소스, PC 포트의
스크립트 실행, 또는 에뮬레이터 오라클로 다시 확인할 수 있다. 본문은 독자를 위한 것이고,
출처는 검증하거나 정정하려는 사람을 위한 것이다. 한국어 페이지는 나중에 영어 페이지 옆에
추가될 수 있다; 영어 페이지가 공식 기록(page of record)이다.

## 계층

| 디렉터리 | 범위 | 페이지가 답하는 것 |
|---|---|---|
| `engine/` | 프로그램이 어떻게 구성되어 있는가 | 부팅, 오버레이, 씬/채널, 디스플레이 오브젝트, 메모리, 스레드, 파일 시스템, 텍스트 시스템 |
| `systems/` | 게임이 어떻게 동작하는가 | 시간, 세이브, 입력, RNG, 날씨/계절, 경제, 주민, 플레이어, 마을, 이벤트, 대화, 네트워크, 오디오 |
| `data/` | 테이블이 무엇을 담고 있는가 | 아이템, 주민, 물고기/곤충, 음악, 아카이브 인덱스: 구조, 위치, 개수, 읽는 방법 |
| `experiments/` | 주장을 어떻게 확인하는가 | 한 페이지에 재현 가능한 레시피 하나: 환경, 예상 관측, 근거 실행 |
| `glossary.md` | 단어 | 페이지 전반에서 사용되는 용어와, 각각을 정의하는 함수 또는 주소 |
| `audits/` | 위키가 자기 자신을 읽는 것 | 감사(audit) 회차당 한 페이지: 모든 발견 사항을 페이지, 문장, 문제, 그리고 적용된 수정 또는 필요한 실험으로 기록 |

## 근거 등급 (모든 주장에 필수)

| 등급 | 의미 | 출처가 명시해야 하는 것 |
|---|---|---|
| **S** 소스 | 매칭된 함수 또는 심볼 테이블에서 읽음 | `func_XXXXXXXX` / 심볼 이름, 모듈, 그리고 `src/matched/` 아래의 파일 |
| **E** 실험 | 포트의 스크립트 실행에서 관측됨 | `scratchpad/` 아래의 실행 디렉터리(또는 `experiments/` 페이지)와 프레임 |
| **O** 오라클 | 같은 레시피 아래의 DeSmuME 레퍼런스에서 관측됨 | `scratchpad/oracle/<dir>`와 프레임 |
| **H** 가설 | 추론된 것으로, 아직 측정되지 않음 | 어떤 실험이 이를 결론지을 것인가 |

두 등급을 가진 주장(S+O, E+O)은 하나만 가진 주장보다 강하다; S만으로는 코드가 무엇을
하는지를 말할 뿐, 게임이 실제로 그렇게 하는 것을 보았다는 뜻은 아니다. **가설**이라는
제목의 페이지 절은 위키가 요청하는 실험의 대기열이다.

## 경계

- 디컴파일된 코드, 화면을 식별하는 데 필요한 짧은 인용 UI 문구를 넘어서는 ROM 문자열,
  사운드나 이미지 에셋, 테이블 덤프는 싣지 않는다. 구조와 동작을 서술하고, 주소와 이름을
  인용한다.
- 팬 위키에서 복사한 주장은 싣지 않는다. 팬 위키의 숫자가 측정된 숫자와 일치하는 경우,
  근거는 측정된 출처이다; 불일치하는 경우, 그렇다고 말한다.
- 포트는 측정 도구이지 진실이 아니다: 포트만의 관측은 등급 E이며, 오라클이 동의하거나(O)
  소스가 설명하기(S) 전까지 E에 머무른다.

페이지 템플릿은 `STYLE.md`를 참조한다.
